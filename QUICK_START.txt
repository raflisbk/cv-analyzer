────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
────────────────────────────────────────────────────────────────────

Problem: "Docker not ready"
Solution:
  → Wait 2-3 minutes after starting Docker Desktop
  → Check icon in system tray is GREEN (not orange/red)
  → Run: docker info (should work)

Problem: "Port 8000 already in use"
Solution:
  → Close any other Python/FastAPI apps
  → Or change port in START_WITH_DOCKER_CHECK.bat

Problem: "Port 3000 already in use"
Solution:
  → Close any other Node/Next.js apps
  → Or change port in frontend/package.json

Problem: "Database connection failed"
Solution:
  → Run: docker compose ps (check if postgres running)
  → Run: cd backend && alembic upgrade head
  → Check DATABASE_URL in backend/.env

cd backend

cd backend
conda activate sbk-cv-analyzer
uvicorn app.main:app --reload --port 8000

# Start frontend (new terminal)
cd frontend
npm run dev
